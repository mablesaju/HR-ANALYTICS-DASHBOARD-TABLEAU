# HR-ANALYTICS-DASHBOARD-TABLEAU
📌 Project Overview

An interactive HR Analytics Dashboard built using Tableau to analyze employee demographics, job satisfaction, and attrition trends.

🎯 Objective

Analyze employee demographics and attrition patterns.

Understand job satisfaction across different job roles.

Identify key workforce trends through data visualization.

📈 Dashboard Features

Employee Distribution by Age Group – Analyzes employee demographics.

Job Satisfaction by Job Role – Compares satisfaction levels across job roles.

Employee Attrition by Education Field – Shows attrition across education fields.

Employee Attrition by Department – Highlights department-wise attrition.

Employee Attrition by Gender – Compares attrition by gender.

Key Performance Indicators (KPIs) – Summarizes important HR metrics.

🛠️ Tools & Technologies

Tableau – Dashboard creation and data visualization.

Excel/CSV – Data preparation, if applicable.

GitHub – Project documentation and sharing
