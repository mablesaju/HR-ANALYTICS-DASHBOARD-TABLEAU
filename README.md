# 📊 HR Analytics Dashboard | Tableau

## Overview

This project is an interactive HR Analytics Dashboard created using Tableau. It explores employee demographics, job satisfaction, and attrition patterns through different dashboard visualizations.

---

## Dashboard Features

- **Employee Distribution by Age Group** – Analyzes employee demographics across different age groups.
- **Job Satisfaction by Job Role** – Compares satisfaction levels across different job roles.
- **Employee Attrition by Education Field** – Displays attrition patterns across education fields.
- **Employee Attrition by Department** – Highlights department-wise employee attrition.
- **Employee Attrition by Gender** – Compares attrition patterns by gender.
- **Key Performance Indicators (KPIs)** – Summarizes important HR metrics.

---

## Objectives

- Analyze employee demographics and attrition patterns.
- Understand job satisfaction across different job roles.
- Identify workforce trends through data visualization.
