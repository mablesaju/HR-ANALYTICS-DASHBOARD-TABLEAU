📊 HR Analytics Dashboard | Tableau
1. Project Overview
An interactive Tableau dashboard that analyzes employee data, job satisfaction, and attrition trends.
2. Objective
- Analyze employee demographics and attrition.
- Understand job satisfaction across job roles.
- Identify workforce trends using KPIs.
3. Dashboard Features
- Employee distribution by age group.
- Job satisfaction by job role.
- Attrition by education field, department, and gender.
- Key HR performance indicators (KPIs).
4. Tools & Technologies
- Tableau – Dashboard creation and visualization.
- Excel/CSV – Data preparation.
- GitHub – Project sharing and documentation.
